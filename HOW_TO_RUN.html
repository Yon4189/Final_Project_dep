Developer Guide

How to Run the Project

Step-by-step instructions for starting the Backend API, Mobile App, and Web Admin Dashboard locally.

Quick Reference

Component Technology Directory URL / Port
Backend API Laravel backend/ http://localhost:8000
Queue Worker Laravel backend/ —
WebSocket Server Reverb backend/ Port 8080
Mobile App Expo mobile_app/ QR Code / Emulator
Web Admin React + Vite web_app/ http://localhost:5173
🖥️

1. Backend (Laravel API)

c:\Final-project\Final-project\backend
1
Open a terminal in the backend folder and install PHP dependencies
$composer install
Only needed once, or after adding new packages.
2
Run database migrations
$php artisan migrate
Requires MySQL to be running with a database named final_project.
3
Start the API server (open 3 separate terminals)
$php artisan serve --host=0.0.0.0 --port=8000
$php artisan queue:work
$php artisan reverb:start --host=0.0.0.0 --port=8080
Each command runs in its own terminal window and stays running.
📱

2. Mobile App (Expo / React Native)

c:\Final-project\Final-project\mobile_app
1
Install Node dependencies
$npm install
⚡ Only needed once, or after package.json changes.
2
Start the Expo development server
$npx expo start
📷 Scan the QR code with Expo Go on your phone.
Or press a (Android emulator) · i (iOS simulator) · w (browser).
🌐

3. Web Admin Dashboard (React + Vite)

c:\Final-project\Final-project\web_app
1
Install Node dependencies
$npm install
2
Start the development server
$npm run dev
🌐 Opens at http://localhost:5173

⚠️ Important Notes

  • Always start the Backend first before the Mobile App or Web Admin.
  • Make sure MySQL is running and the final_project database exists.
  • The backend must use --host=0.0.0.0 so the mobile app on your phone can reach it via your local network IP.
  • The mobile app auto-detects your machine's LAN IP through Expo — no manual IP config needed.
