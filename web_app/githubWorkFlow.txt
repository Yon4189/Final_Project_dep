           2. The Daily Workflow (The "Safe" Cycle)
To avoid those "revert" errors you had earlier, follow this exact order every time you sit down to work.

Step A: Pull (Refresh)
Before you type a single line of code, get the latest work from your teammates.

Click the Source Control icon on the left sidebar.

Click the three dots (...) at the top of the Source Control menu.

Select Pull.



       3. Create Branch and merging Phases
🟢 Phase 1: Create a New Branch
Look at the bottom-left corner of VS Code. It likely says main. Click on the word main.
A menu will open at the top. Select + Create new branch....
Type your branch name: feat-admin-setup and press Enter.
Notice the bottom-left corner now says feat-admin-setup. You are now safe to work!
🟡 Phase 2: Staging and Committing Changes
Once you have initialized the project or changed files in web-app/:
Click the Source Control icon (or press Ctrl + Shift + G).
You will see a list of changed files under Changes.
Stage Files: Hover over the word "Changes" and click the + (plus sign) to "Stage All Changes". They move up to Staged Changes.
Write Message: In the box that says "Message", type: feat: initialize web-app with vite and tailwind.
Commit: Click the blue Commit button.
🔵 Phase 3: Pushing to GitHub
After committing, the blue button will change to Publish Branch.
Click Publish Branch.
This sends your code to the GitHub website.
🟠 Phase 4: Merging (The Pull Request)
Note: While there are extensions for this, it is standard practice to do the final merge on the GitHub website so your teammates can see the UI and leave comments.
Go to your repo on GitHub.com.
A green button usually appears: Compare & pull request. Click it.
Click Create pull request.
Once reviewed, click the green Merge pull request and Confirm merge.
🔴 Phase 5: Syncing back to Main (Inside VS Code)
Now that your work is officially in the main branch on the website, you need to update your local VS Code:
Switch back to main: Click the branch name (feat-admin-setup) in the bottom-left corner.
Select main from the list.
Pull changes: In the Source Control tab, click the ... (three dots) at the top and select Pull.
Or simply click the "Sync" icon (circular arrows) in the bottom-left corner.
